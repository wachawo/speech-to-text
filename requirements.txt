# server's install, which needs the model backend.

# pinned in Dockerfile / Dockerfile-cpu and in requirements-gpu.txt /
# requirements-cpu.txt.
#
# The diarization backend is not here either: it is opt-in, and lives in
# requirements-diarize.txt, installed only for a `--build-arg DIARIZE=true` image.
